FAQ

the four questions everyone asks
Do I need Horizon, or can I join with the normal client?

Horizon is what we run, and it's the client the world is tested on. A stock 26.3 client with the same Fabric mods usually works, but the server's settings target Horizon.

Is there a store or pay-to-win?

No store, no ranks, no kits. Nobody can buy power here.

Will the world reset when the game updates?

Only if the server votes for it. Updates that can be applied in place get applied in place.

Can I bring my own mods?

Client-side QoL is fine — maps, shaders, HUD tweaks. Anything that changes blocks, items or recipes has to match the server's pack, so check #modlist first.

Come build something

The world is up and the whitelist is open. All you need is the Discord and a mods folder.
